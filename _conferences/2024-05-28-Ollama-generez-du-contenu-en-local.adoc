== 1. Abstract

Avez-vous déjà pensé à tester des LLM (Large Language Models) afin de découvrir leurs différentes possibilités ?

Je vous propose de découvrir Ollama, une solution pour installer et utiliser des LLM sur votre machine.
Nous utiliserons des modèles tels que Mistral, LLaVA, Llama 3, etc. afin de découvrir différents cas d'utilisation.
